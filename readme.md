# Tutorials

A collection of programming tutorials and hands-on examples. Each tutorial lives in its own directory with source code and a README covering prerequisites, setup, and usage.

## Available tutorials

| Tutorial | Technology | What you'll learn |
| --- | --- | --- |
| [Spring Boot Hello World](spring-hello-world/readme.md) | Java, Spring Boot, Maven | Build a simple HTTP endpoint, use controllers and services, understand dependency injection, and write unit tests with JUnit and Mockito. |

## Getting started

Choose a tutorial above, open its directory, and follow its README. Requirements and commands are specific to each tutorial.

## Adding tutorials

Create a separate directory for each tutorial. Include its source code and a README with prerequisites, instructions to run it, and any test commands. Add a link to the table above so it is easy to find.
